*** 32.11 File Comparison with Dired [[#File-Comparison-with-Dired][¶]]
:PROPERTIES:
:CUSTOM_ID: File-Comparison-with-Dired
:CLASS: section
:END:
The = (=dired-diff=) command compares the current file (the file at point) with another file (read using the minibuffer) using the =diff= program. The file specified with the minibuffer is the first argument of =diff=, and file at point is the second argument. The output of the =diff= program is shown in a buffer using Diff mode (see [[id:emacs--Comparing-Files][Comparing Files]]).

If the region is active, the default for the file read using the minibuffer is the file at the mark (i.e., the ordinary Emacs mark, not a Dired mark; see [[id:emacs--Setting-Mark][Setting the Mark]]). Otherwise, if the file at point has a backup file (see [[id:emacs--Backup][Backup Files]]), that is the default.

You could also compare files using =ediff-files=, see [[../ediff_html/Major-Entry-Points.html#Major-Entry-Points][Major Entry Points]] in Ediff User's Manual.
