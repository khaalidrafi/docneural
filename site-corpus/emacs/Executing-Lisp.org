*** 29.7 Executing Lisp Expressions [[#Executing-Lisp-Expressions][¶]]
:PROPERTIES:
:CUSTOM_ID: Executing-Lisp-Expressions
:CLASS: section
:END:
Emacs has major modes for several variants of Lisp. They use the same editing commands as other programming language modes (see [[id:emacs--Programs][Editing Programs]]). In addition, they provide special commands for executing Lisp expressions.

- Emacs Lisp mode :: The mode for editing Emacs Lisp source files. It defines C-M-x to evaluate the current top-level Lisp expression. See [[id:emacs--Lisp-Eval][Evaluating Emacs Lisp Expressions]].

- Lisp Interaction mode :: The mode for an interactive Emacs Lisp session. It defines C-j to evaluate the expression before point and insert its value in the buffer. See [[id:emacs--Lisp-Interaction][Lisp Interaction Buffers]].

- Lisp mode :: The mode for editing source files of programs that run in Lisps other than Emacs Lisp. It defines C-M-x to evaluate the current top-level expression in an external Lisp. See [[id:emacs--External-Lisp][Running an External Lisp]].

- Inferior Lisp mode :: The mode for an interactive session with an external Lisp which is being run as a subprocess (or /inferior process/) of Emacs. See [[id:emacs--External-Lisp][Running an External Lisp]].

- Scheme mode :: Like Lisp mode, but for Scheme programs.

- Inferior Scheme mode :: Like Inferior Lisp mode, but for Scheme.
