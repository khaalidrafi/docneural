*** 15.7 Keyboard Macro Registers [[#Keyboard-Macro-Registers-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Keyboard-Macro-Registers-1
:CLASS: section
:END:
If you need to execute a keyboard macro (see [[id:emacs--Keyboard-Macros][Keyboard Macros]]) frequently, it is more convenient to put it in a register or save it (see [[id:emacs--Save-Keyboard-Macro][Naming and Saving Keyboard Macros]]). C-x C-k x =r= (=kmacro-to-register=) stores the last keyboard macro in register =r=.

To execute the keyboard macro in register =r=, type C-x r j =r=. (This is the same command used to jump to a position or restore a frameset.)
