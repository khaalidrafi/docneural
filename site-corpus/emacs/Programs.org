** 28 Editing Programs [[#Editing-Programs][¶]]
:PROPERTIES:
:CUSTOM_ID: Editing-Programs
:CLASS: chapter
:END:
This chapter describes Emacs features for facilitating editing programs. Some of the things these features can do are:

- Find or move over top-level definitions (see [[id:emacs--Defuns::#Defuns][Top-Level Definitions, or Defuns]]).
- Apply the usual indentation conventions of the language (see [[id:emacs--Program-Indent::#Program-Indent][Indentation for Programs]]).
- Balance parentheses (see [[id:emacs--Parentheses::#Parentheses][Commands for Editing with Parentheses]]).
- Insert, kill or align comments (see [[id:emacs--Comments::#Comments][Manipulating Comments]]).
- Highlight program syntax (see [[id:emacs--Font-Lock::#Font-Lock][Font Lock mode]]).
