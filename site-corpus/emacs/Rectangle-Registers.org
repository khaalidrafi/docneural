*** 15.3 Saving Rectangles in Registers [[#Saving-Rectangles-in-Registers][¶]]
:PROPERTIES:
:CUSTOM_ID: Saving-Rectangles-in-Registers
:CLASS: section
:END:
A register can contain a rectangle instead of linear text. See [[id:emacs--Rectangles][Rectangles]], for basic information on how to specify a rectangle in the buffer.

-  <<index-copy_002drectangle_002dto_002dregister>>C-x r r =r= [[#index-copy_002drectangle_002dto_002dregister][¶]] :: Copy the region-rectangle into register =r= (=copy-rectangle-to-register=). With prefix argument, delete it as well.

- C-x r i =r= :: Insert the rectangle stored in register =r= (if it contains a rectangle) (=insert-register=).

The C-x r i =r= (=insert-register=) command, previously documented in [[id:emacs--Text-Registers][Saving Text in Registers]], inserts a rectangle rather than a text string, if the register contains a rectangle.
