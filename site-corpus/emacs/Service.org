** 56 How To Get Help with GNU Emacs [[#How-To-Get-Help-with-GNU-Emacs][¶]]
:PROPERTIES:
:CUSTOM_ID: How-To-Get-Help-with-GNU-Emacs
:CLASS: chapter section-level-set-chapter
:END:
If you need help installing, using or changing GNU Emacs, there are two ways to find it:

- Send a message to [[https://lists.gnu.org/mailman/listinfo/help-gnu-emacs][the help-gnu-emacs mailing list]], or post your request on newsgroup =gnu.emacs.help=. (This mailing list and newsgroup interconnect, so it does not matter which one you use.)
- Look in the [[https://www.fsf.org/resources/service/][service directory]] for someone who might help you for a fee.
