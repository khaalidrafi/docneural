**** 30.4.1.2 Commands Available in the =*xref*= Buffer [[#Commands-Available-in-the-_002axref_002a-Buffer][¶]]
:PROPERTIES:
:CUSTOM_ID: Commands-Available-in-the-_002axref_002a-Buffer
:CLASS: subsubsection
:END:
The following commands are provided in the =*xref*= buffer by the special XREF mode:

- RET\\
  mouse-1 :: Display the reference on the current line (=xref-goto-xref=). With prefix argument, also bury the =*xref*= buffer.

- <<index-xref_002dselect_002dand_002dshow_002dxref>>mouse-2 [[#index-xref_002dselect_002dand_002dshow_002dxref][¶]] :: The same as =mouse-1=, but make the window displaying the =*xref*= buffer the selected window (=xref-select-and-show-xref=).

- <<index-xref_002dnext_002dline>>n [[#index-xref_002dnext_002dline][¶]]\\
  . :: Move to the next reference and display it in the other window (=xref-next-line=).

- <<index-xref_002dnext_002dgroup>>N [[#index-xref_002dnext_002dgroup][¶]] :: Move to the first reference of the next reference group and display it in the other window (=xref-next-group=).

- <<index-xref_002dprev_002dline>>p [[#index-xref_002dprev_002dline][¶]]\\
  , :: Move to the previous reference and display it in the other window (=xref-prev-line=).

- <<index-xref_002dprev_002dgroup>>P [[#index-xref_002dprev_002dgroup][¶]] :: Move to the first reference of the previous reference group and display it in the other window (=xref-prev-group=).

- <<index-xref_002dshow_002dlocation_002dat_002dpoint>>C-o [[#index-xref_002dshow_002dlocation_002dat_002dpoint][¶]] :: Display the reference on the current line in the other window (=xref-show-location-at-point=).

- r =pattern= RET =replacement= RET :: Perform interactive query-replace on references that match =pattern= (=xref-query-replace-in-results=), replacing the match with =replacement=. This command can only be used in =*xref*= buffers that show all the matches for an identifier in all the relevant files. See [[id:emacs--Identifier-Search][Searching and Replacing with Identifiers]].

- <<index-revert_002dbuffer_002c-in-_002axref_002a-buffers>>g [[#index-revert_002dbuffer_002c-in-_002axref_002a-buffers][¶]] :: Refresh the contents of the =*xref*= buffer (=revert-buffer=). See [[id:emacs--Reverting][Reverting a Buffer]].

- <<index-xref_002dquit_002dand_002dpop_002dmarker_002dstack>>M-, [[#index-xref_002dquit_002dand_002dpop_002dmarker_002dstack][¶]] :: Quit the window showing the =*xref*= buffer, and then jump to the previous Xref stack location (=xref-quit-and-pop-marker-stack=).

- <<index-xref_002dquit>>q [[#index-xref_002dquit][¶]] :: Quit the window showing the =*xref*= buffer (=xref-quit=).

In addition, the usual navigation commands, such as the arrow keys, C-n, and C-p are available for moving around the buffer without displaying the references.
