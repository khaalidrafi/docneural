*** 3.7 After System Installation
:PROPERTIES:
:CUSTOM_ID: after-system-installation
:CLASS: section
:END:
Success, you've now booted into Guix System! Login to the system using the non-=root= user that you created during installation. You can upgrade the system whenever you want by running:

#+begin_example
guix pull
sudo guix system reconfigure /etc/config.scm
#+end_example

This builds a new system /generation/ with the latest packages and services.

Now, see [[id:guix--Getting-Started-with-the-System][Getting Started]], and join us on =#guix= on the Libera.Chat IRC network or on [[mailto:guix-devel@gnu.org][guix-devel@gnu.org]] to share your experience!
