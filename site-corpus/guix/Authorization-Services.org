**** OpenDoas Service [[#OpenDoas-Service][¶]]
:PROPERTIES:
:CUSTOM_ID: OpenDoas-Service
:CLASS: subsubheading
:END:
[[https://github.com/Duncaen/OpenDoas][OpenDoas]] is a portable fork of OpenBSD's =doas=, a minimal replacement for the venerable sudo.

A simple ruleset allowing users in the wheel group to execute arbitrary commands, and running =halt= and =reboot= without being prompted for a password can be specified like this:

#+begin_src lisp
(service opendoas-service-type
         (opendoas-configuration
           (rules (cons (opendoas-permit-rule
                         (identity ":wheel"))
                        (map (lambda (cmd)
                               (opendoas-permit-rule
                                (identity ":wheel")
                                (nopass? #t)
                                (command cmd)
                                (args '())))
                             `("halt" "reboot"))))))
#+end_src

- Variable: *opendoas-service-type* [[#index-opendoas_002dservice_002dtype][¶]] :: The OpenDoas service. Takes an =opendoas-configuration= as its value. By default, this service configures OpenDoas in /etc/doas.conf and adds it to /run/privileged with its setuid bit set.

- Data Type: *opendoas-configuration* [[#index-opendoas_002dconfiguration][¶]] :: The configuration for OpenDoas, with the following fields:

  - =package= (default: =opendoas=) (type: package) :: The OpenDoas package to use.

  - =rules= (type: list-of-opendoas-rule) :: List of permit and/or deny rules used by OpenDoas. Defaults to =(list (opendoas-permit-rule (identity ":wheel")))=.

- Data Type: *=opendoas-permit-rule=* [[#index-opendoas_002dpermit_002drule][¶]] :: Permit rule for OpenDoas, with the following fields:

  - =nopass?= (default: =#f=) (type: boolean) :: Whether the user should be permitted to run the command without a password.

  - =nolog?= (default: =#f=) (type: boolean) :: Wheter sucessful command execution should be logged.

  - =persist?= (default: =#f=) (type: boolean) :: When true, ther after the user sucessfully authenticates, do not ask for a password again for some time.

  - =keepenv?= (default: =#f=) (type: boolean) :: Wheter environment variables other than those listed in doas should be retained when creating the enviroment for the new process.

  - =identity= (type: string) :: The username to match. Groups may be specified by prepending a colon ':'.

  - =as-user= (type: maybe-string) :: The target user the running user is allowed to run the command as. The default is all users.

  - =command= (type: maybe-string) :: The command the user is allowed to run. The default is all commands. It's preferable to have commands specifieds by absolute paths. If a relative path is specified, only a restricted PATH will be searched.

  - =args= (type: maybe-list-of-string) :: Arguments to command. The command arguments provided by the user need to match those specified. The keyword args alone means that command must be run without arguments.

  - =setenv= (type: maybe-alist) :: Set the specified variables. Variables may also be removed by setting them to #f, or simply exported, by setting them to #t. If the first character of the value is =$= then the value to be set is taken from the existing environment variable with the given name.

Data Type: *=opendoas-deny-rule=* [[#index-opendoas_002ddeny_002drule][¶]]
Deny rule for OpenDoas, with the following fields:

=identity= (type: string)
=as-user= (type: maybe-string)
=command= (type: maybe-string)
=args= (type: maybe-list-of-string)
All the above as in opendoas-permit-rule.

Other services are able to extend =opendoas-service-type= by supplying to it a list of opendoas-rules.
