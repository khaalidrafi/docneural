**** 13.3.10 Backup Services
:PROPERTIES:
:CUSTOM_ID: backup-services
:CLASS: subsection
:END:
The =(gnu home services backup)= module offers services for backing up file system trees. For now, it provides the =home-restic-backup-service-type=.

With =home-restic-backup-service-type=, you can periodically back up directories and files with [[https://restic.net/][Restic]], which supports end-to-end encryption and deduplication. Consider the following configuration:

#+begin_src lisp
(use-modules (gnu home services backup) ;for 'restic-backup-job', 'home-restic-backup-service-type'
             (gnu packages sync)        ;for 'rclone'
             …)

(home-environment

  (packages (list rclone    ;for use by restic
                  …))
  (services
    (list
      …
      (simple-service 'backup-jobs
                      home-restic-backup-service-type
                      (list (restic-backup-job
                              (name "remote-ftp")
                              (repository "rclone:remote-ftp:backup/restic")
                              (password-file "/home/alice/.restic")
                              ;; Every day at 23.
                              (schedule "0 23 * * *")
                              (files '("/home/alice/.restic"
                                       "/home/alice/.config/rclone"
                                       "/home/alice/Pictures"))))))))
#+end_src

In general it is preferable to extend the =home-restic-backup-service-type=, as shown in the example above. This is because it takes care of wrapping everything with =for-home=, which enables the =home-restic-backup-service-type= and =restic-backup-service-type= to share the same codebase.

For a custom configuration, wrap your =restic-backup-configuration= in =for-home=, as in this example:

#+begin_src lisp
(use-modules (gnu services)             ;for 'for-home'
             (gnu services backup)      ;for 'restic-backup-job' and 'restic-backup-configuration'
             (gnu home services backup) ;for 'home-restic-backup-service-type'
             (gnu packages sync)        ;for 'rclone'
             …)

(home-environment

  (packages (list rclone    ;for use by restic
                  …))
  (services
    (list
      …
      (service home-restic-backup-service-type
               (for-home
                (restic-backup-configuration
                 (jobs (list …))))))))
#+end_src

You can refer to see [[id:guix--Miscellaneous-Services][=restic-backup-service-type=]] for details about =restic-backup-configuration= and =restic-backup-job=. The only difference is that the =home-restic-backup-service-type= will ignore the =user= and =group= field of =restic-backup-job=.
