**** 11.10.27 DAV Services [[#DAV-Services-1][¶]]
:PROPERTIES:
:CUSTOM_ID: DAV-Services-1
:CLASS: subsection
:END:
- Variable: *xandikos-service-type* [[#index-xandikos_002dservice_002dtype][¶]] :: This service starts =xandikos=, a lightweight CardDAV/CalDAV server backed by a Git repository.

  The service's value is a =xandikos-configuration= record.

- Data Type: *xandikos-configuration* [[#index-xandikos_002dconfiguration][¶]] :: This is the data type representing the configuration for the =xandikos-shepherd-service=.

  It has the following parameters:

  - =package= (default: =xandikos=) :: The =xandikos= package to use.

  - =directory= (default: ="/var/xandikos/dav"=) :: The directory to serve from.

  - =listen-address= (default: =127.0.0.1=) :: The address =xandikos= listens on.

  - =port= (default: =8080=) :: The port to run =xandikos= on.

  - =current-user-principal= (default: ="/user/"=) :: Path to current user principal.

  - =route-prefix= (default: ="/"=) :: Path to =xandikos= (useful when Xandikos is behind a reverse proxy).

  - =defaults?= (default: =#t=) :: Create initial calendar and address book. Implies =--autocreate=.

  - =dump?= (default: =#f=) :: Print DAV XML request/responses.

  - =avahi?= (default: =#f=) :: Announce services with avahi.

  - =autocreate?= (default: =#f=) :: Automatically create necessary directories.

  - =no-strict?= (default: =#f=) :: Enable workarounds for buggy CalDAV/CardDAV client implementations.
