*** 6.4 Downloading a List of Channels [[#Downloading-a-List-of-Channels-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Downloading-a-List-of-Channels-1
:CLASS: section
:END:
In some cases, you might want to delegate maintenance of your set of channels to a third party---a person responsible for this in your team, or perhaps an automated system that publishes a channel file when some criteria are met (see [[id:guix--Channels-with-Substitutes][Channels with Substitutes]], for an example of that).

In that case you can make your channel file an /alias/ for some downloaded channel file, as in the example below:

#+begin_src lisp
;; Use the channels published at example.org.
(downloaded-channels "https://example.org/channels.scm")
#+end_src

If you save the content above as =~/.config/guix/channels.scm=, every time you run =guix pull= it will first download the given channel file and then pull from the channels it specifies.

This mechanism is safe because, by default, the channel file itself is evaluated in an isolated environment (see [[id:guix--Invoking-guix-pull::#channel_002devaluation][=guix pull= channel evaluation]]), and because only /trusted channels/ are accepted (see [[id:guix--Invoking-guix-pull::#trusted_002dchannels][the definition of “trusted channels”]]). Likewise, the =--max-indirections= option of =guix pull= allows you to set an upper bound on the number of times a channel file might create an indirection to another channel file /via/ =downloaded-channels=.

#+begin_quote
*Note:* =downloaded-channels= causes the download a channel file as currently provided by a server; the contents of that file may change over time, or the server might stop providing it altogether.

For reproducibility purposes, you may want to track the output of =guix describe= (see [[id:guix--Replicating-Guix][Replicating Guix]]).

#+end_quote

The =downloaded-channels= is exported by =(guix channels)= and defined below.

- Procedure: *downloaded-channels* =uri== [#:append ’()]= [[#index-downloaded_002dchannels][¶]] :: Return an opaque object representing a list of channels to be downloaded from =uri=, a string. =uri= can be either an HTTP or HTTPS URL, or a [[https://swhid.org][Software Hash Identifier]] (SWHID) denoting a channel file.

  Optionally, =#:append= can specify a list of channels to be appended to those downloaded from =uri=.

  #+begin_quote
  *Note:* This procedure does /not/ return a list of channels. Thus it cannot be composed with other channel lists by calling =append=, it cannot be traversed with =map=, and so on. This restriction might be lifted in the future; you can also use =#:append= to append a list of channels to the result.

  #+end_quote
