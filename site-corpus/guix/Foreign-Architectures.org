** 10 Foreign Architectures
:PROPERTIES:
:CUSTOM_ID: foreign-architectures
:CLASS: chapter
:END:
You can target computers of different CPU architectures when producing packages (see [[id:guix--Invoking-guix-package][Invoking =guix package=]]), packs (see [[id:guix--Invoking-guix-pack][Invoking =guix pack=]]) or full systems (see [[id:guix--Invoking-guix-system][Invoking =guix system=]]).

GNU Guix supports two distinct mechanisms to target foreign architectures:

1. The traditional [[https://en.wikipedia.org/wiki/Cross_compiler][cross-compilation]] mechanism.
2. The native building mechanism which consists in building using the CPU instruction set of the foreign system you are targeting. It often requires emulation, using the QEMU program for instance.
