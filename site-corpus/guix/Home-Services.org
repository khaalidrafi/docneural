<<Home-Services-1>>
*** 13.3 Home Services
:PROPERTIES:
:CUSTOM_ID: home-services
:CLASS: section
:END:
<<index-home-services>>
A /home service/ is not necessarily something that has a daemon and is managed by Shepherd (see [[https://www.gnu.org/software/shepherd/manual/html_node/Jump-Start.html#Jump-Start][Jump Start]] in The GNU Shepherd Manual), in most cases it doesn't. It's a simple building block of the home environment, often declaring a set of packages to be installed in the home environment profile, a set of config files to be symlinked into =XDG_CONFIG_HOME= (=~/.config= by default), and environment variables to be set by a login shell.

There is a service extension mechanism (see [[id:guix--Service-Composition][Service Composition]]) which allows home services to extend other home services and utilize capabilities they provide; for example: declare mcron jobs (see [[https://www.gnu.org/software/mcron/manual/html_node/index.html#Top][GNU Mcron]]) by extending [[id:guix--Mcron-Home-Service][Scheduled User's Job Execution]]; declare daemons by extending [[id:guix--Shepherd-Home-Service][Managing User Daemons]]; add commands, which will be invoked on by the Bash by extending [[id:guix--Shells-Home-Services][=home-bash-service-type=]].

A good way to discover available home services is using the =guix home search= command (see [[id:guix--Invoking-guix-home][Invoking =guix home=]]). After the required home services are found, include its module with the =use-modules= form (see [[https://www.gnu.org/software/guile/manual/html_node/use_002dmodules.html#use_002dmodules][Using Guile Modules]] in The GNU Guile Reference Manual), or the =#:use-modules= directive (see [[https://www.gnu.org/software/guile/manual/html_node/define_002dmodule.html#define_002dmodule][Creating Guile Modules]] in The GNU Guile Reference Manual) and declare a home service using the =service= function, or extend a service type by declaring a new service with the =simple-service= procedure from =(gnu services)=.
