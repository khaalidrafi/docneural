**** 2.1.1 Installation with a pre-mounted store [[#Installation-with-a-pre_002dmounted-store-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Installation-with-a-pre_002dmounted-store-1
:CLASS: subsection
:END:
If you need to install Guix on a system whose main file system is too small (as can be the case for the rescue environments of VPS (Virtual Private Servers), for example), you may need to expose the =/gnu= directory from a different storage device/partition. This can be achieved by mounting a secondary partition or directory at =/gnu=, via a bind mount for example. In the bind mount case, assuming the partition that should be used to hold the content of the store is mounted at =/mnt=, you could proceed like this /before/ starting the installation:

#+begin_example
mkdir /mnt/gnu
mkdir /gnu
mount --bind /mnt/gnu /gnu
#+end_example

#+begin_quote
*Important:* If your foreign distribution uses systemd, do not attempt to mount directly on the store directory, =/gnu/store=, as this would conflict with the =gnu-store.mount= systemd unit and cause the =guix-daemon.service= to unmount it before starting, failing its execution. Mount on =/gnu= instead.

#+end_quote
