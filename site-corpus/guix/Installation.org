<<index-installing-Guix>> <<index-foreign-distro>> <<index-Guix-System-2>>
You can install the package management tool Guix on top of an existing GNU/Linux or GNU/Hurd system[[#FOOT4][^{4}]], referred to as a /foreign distro/. If, instead, you want to install the complete, standalone GNU system distribution, /Guix System/, see [[id:guix--System-Installation][System Installation]]. This section is concerned only with the installation of Guix on a foreign distro.

#+begin_quote
*Important:* This section only applies to systems without Guix. Following it for existing Guix installations will overwrite important system files.

#+end_quote

<<index-directories-related-to-foreign-distro>>
When installed on a foreign distro, GNU Guix complements the available tools without interference. Its data lives exclusively in two directories, usually =/gnu/store= and =/var/guix=; other files on your system, such as =/etc=, are left untouched.

Once installed, Guix can be updated by running =guix pull= (see [[id:guix--Invoking-guix-pull][Invoking =guix pull=]]).
