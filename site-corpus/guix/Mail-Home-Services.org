**** 13.4.14 Mail Home Services [[#Mail-Home-Services-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Mail-Home-Services-1
:CLASS: subsection
:END:
The =(gnu home services mail)= module provides services that help you set up the tools to work with emails in your home environment.

**** MSMTP Service [[#MSMTP-Service][¶]]
:PROPERTIES:
:CUSTOM_ID: MSMTP-Service
:CLASS: subsubheading
:END:
[[https://marlam.de/msmtp][MSMTP]] is a SMTP (Simple Mail Transfer Protocol) client. It sends mail to a predefined SMTP server that takes care of proper delivery.

The service reference is given below.

- Variable: *home-msmtp-service-type* [[#index-home_002dmsmtp_002dservice_002dtype][¶]] :: This is the service type for =msmtp=. Its value must be a =home-msmtp-configuration=, as shown below. It provides the =~/.config/msmtp/config= file.

  As an example, here is how you would configure =msmtp= for a single account:

  #+begin_src lisp
  (service home-msmtp-service-type
           (home-msmtp-configuration
            (accounts
             (list
              (msmtp-account
               (name "alice")
               (configuration
                (msmtp-configuration
                 (host "mail.example.org")
                 (port 587)
                 (user "alice")
                 (password-eval "pass Mail/alice"))))))))
  #+end_src

- Data Type: *home-msmtp-configuration* [[#index-home_002dmsmtp_002dconfiguration][¶]] :: Available =home-msmtp-configuration= fields are:

  - =defaults= (type: msmtp-configuration) :: The configuration that will be set as default for all accounts.

  - =accounts= (default: ='()=) (type: list-of-msmtp-accounts) :: A list of =msmtp-account= records which contain information about all your accounts.

  - =default-account= (type: maybe-string) :: Set the default account.

  - =extra-content= (default: =""=) (type: string) :: Extra content appended as-is to the configuration file. Run =man msmtp= for more information about the configuration file format.

- Data Type: *msmtp-account* [[#index-msmtp_002daccount][¶]] :: Available =msmtp-account= fields are:

  - =name= (type: string) :: The unique name of the account.

  - =configuration= (type: msmtp-configuration) :: The configuration for this given account.

- Data Type: *msmtp-configuration* [[#index-msmtp_002dconfiguration][¶]] :: Available =msmtp-configuration= fields are:

  - =auth?= (type: maybe-boolean) :: Enable or disable authentication.

  - =tls?= (type: maybe-boolean) :: Enable or disable TLS (also known as SSL) for secured connections.

  - =tls-starttls?= (type: maybe-boolean) :: Choose the TLS variant: start TLS from within the session (‘on', default), or tunnel the session through TLS (‘off').

  - =tls-trust-file= (type: maybe-string) :: Activate server certificate verification using a list of trusted Certification Authorities (CAs).

  - =log-file= (type: maybe-string) :: Enable logging to the specified file. An empty argument disables logging. The file name ‘-' directs the log information to standard output.

  - =host= (type: maybe-string) :: The SMTP server to send the mail to.

  - =port= (type: maybe-integer) :: The port that the SMTP server listens on. The default is 25 ("smtp"), unless TLS without STARTTLS is used, in which case it is 465 ("smtps").

  - =user= (type: maybe-string) :: Set the user name for authentication.

  - =from= (type: maybe-string) :: Set the envelope-from address.

  - =password-eval= (type: maybe-string) :: Set the password for authentication to the output (stdout) of the command cmd.

  - =extra-content= (default: =""=) (type: string) :: Extra content appended as-is to the configuration block. Run =man msmtp= for more information about the configuration file format.

**** Goimapnotify Service [[#Goimapnotify-Service][¶]]
:PROPERTIES:
:CUSTOM_ID: Goimapnotify-Service
:CLASS: subsubheading
:END:
- Variable: *home-goimapnotify-service-type* [[#index-home_002dgoimapnotify_002dservice_002dtype][¶]] :: This is the type of the service that runs [[https://gitlab.com/shackra/goimapnotify][Goimapnotify]], a command-line application to execute scripts on IMAP mailbox changes using [[https://www.rfc-editor.org/info/rfc2177][IDLE]]. Its value is a =home-goimapnotify-configuration= object.

Here is a snippet of the service with an example configuration that you could add to the =services= field of your =home-environment=:

#+begin_src lisp
(service home-goimapnotify-service-type
         (home-goimapnotify-configuration
          (configurations
           (list
            (goimapnotify-configuration
             (host "imap.example.com")
             (tls? #t)
             (tls-options
              (goimapnotify-tls-options-configuration
               (reject-unauthorized? #t)))
             (user-name "alice@example.com")
             (password-command
              #~(string-append #$(file-append libsecret "/bin/secret-tool")
                               " lookup user alice@example.com"))
             (boxes
              (list
               (goimapnotify-box-configuration
                (mailbox "Inbox")
                (on-new-mail
                 #~(string-append #$(file-append isync "/bin/mbsync")
                                  " alice"))
                (on-new-mail-post
                 #~(string-append #$(file-append notmuch "/bin/notmuch")
                                  " new"))))))))))
#+end_src

- Data Type: *home-goimapnotify-configuration* [[#index-home_002dgoimapnotify_002dconfiguration][¶]] :: Available =home-goimapnotify-configuration= fields are:

  - =goimapnotify= (default: =goimapnotify=) (type: file-like) :: The =goimapnotify= package to use.

  - =configurations= (type: list-of-goimapnotify-configurations) :: A list of =goimapnotify-configuration= records which contain information about all your accounts configurations.

  - =shepherd-requirement= (default: =()=) (type: list-of-symbols) :: A list of services that should be started before this service. For example, to make the service start after the gpg-agent service, (see [[id:guix--GNU-Privacy-Guard][GNU Privacy Guard]]), one could write the following:

    #+begin_src lisp
    (shepherd-requirement '(gpg-agent))
    #+end_src

- Data Type: *goimapnotify-configuration* [[#index-goimapnotify_002dconfiguration][¶]] :: Available =goimapnotify-configuration= fields are:

  - =host= (type: string) :: The IMAP server hostname.

  - =host-command= (type: maybe-string-or-gexp) :: The command to retrieve the IMAP server hostname.

  - =port= (default: =993=) (type: integer) :: The port that the IMAP server listens on.

  - =tls?= (default: =#f=) (type: boolean) :: Enable or disable TLS.

  - =tls-options= (type: maybe-goimapnotify-tls-options-configuration) :: TLS options for the IMAP connection.

  - =idle-logout-timeout= (type: maybe-integer) :: The idle logout timeout in minutes.

  - =user-name= (type: maybe-string) :: The user-name for authentication.

  - =user-name-command= (type: maybe-string-or-gexp) :: The command to retrieve the user-name.

  - =alias= (type: maybe-string) :: An alias for the account.

  - =password= (type: maybe-string) :: The password for authentication.

  - =password-command= (type: maybe-string-or-gexp) :: The command to retrieve the password.

  - =xo-auth2?= (default: =#f=) (type: boolean) :: Enable or disable XOAUTH2 authentication.

  - =wait= (type: maybe-integer) :: The delay in seconds before the mail syncing is triggered.

  - =boxes= (type: list-of-goimapnotify-boxes-configurations) :: The mailboxes to monitor.

- Data Type: *goimapnotify-box-configuration* [[#index-goimapnotify_002dbox_002dconfiguration][¶]] :: Available =goimapnotify-box-configuration= fields are:

  - =mailbox= (type: string) :: The mailbox to monitor.

  - =on-new-mail= (type: maybe-string-or-gexp) :: The command to execute when new mail arrives.

  - =on-new-mail-post= (type: maybe-string-or-gexp) :: The command to execute after the new-mail command.

  - =on-changed-mail= (type: maybe-string-or-gexp) :: The command to execute when mail is changed.

  - =on-changed-mail-post= (type: maybe-string-or-gexp) :: The command to execute after the changed-mail command.

  - =on-deleted-mail= (type: maybe-string-or-gexp) :: The command to execute when mail is deleted.

  - =on-deleted-mail-post= (type: maybe-string-or-gexp) :: The command to execute after the deleted-mail command.

- Data Type: *goimapnotify-tls-options-configuration* [[#index-goimapnotify_002dtls_002doptions_002dconfiguration][¶]] :: Available =goimapnotify-tls-options-configuration= fields are:

  - =reject-unauthorized?= (default: =#f=) (type: boolean) :: Whether to reject unauthorized TLS certificates.

  - =starttls?= (default: =#f=) (type: boolean) :: Whether to use STARTTLS.
