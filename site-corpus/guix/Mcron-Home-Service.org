**** 13.3.3 Scheduled User's Job Execution
:PROPERTIES:
:CUSTOM_ID: scheduled-users-job-execution
:CLASS: subsection
:END:
<<index-cron_002c-per_002duser>> <<index-mcron_002c-per_002duser>> <<index-scheduling-jobs-per_002duser>>
The =(gnu home services mcron)= module provides an interface to GNU mcron, a daemon to run jobs at scheduled times (see [[https://www.gnu.org/software/mcron/manual/html_node/index.html#Top][GNU mcron]]). The information about system's mcron is applicable here (see [[id:guix--Scheduled-Job-Execution::#mcron_002dservice][mcron reference]]), the only difference for home services is that they have to be declared in a =home-environment= record instead of an =operating-system= record.

#+begin_quote
*Note:* We recommend defining periodic tasks as Shepherd timers, which provide more flexibility than mcron. See [[id:guix--Shepherd-Home-Service][Managing User Daemons]], for more info.

#+end_quote

- Variable: home-mcron-service-type  :: This is the type of the =mcron= home service, whose value is a =home-mcron-configuration= object. It allows to manage scheduled tasks.

  This service type can be the target of a service extension that provides additional job specifications (see [[id:guix--Service-Composition][Service Composition]]). In other words, it is possible to define services that provide additional mcron jobs to run.

- Data Type: home-mcron-configuration  :: Available =home-mcron-configuration= fields are:

  - =mcron= (default: =mcron=) (type: file-like) :: The mcron package to use.

  - =jobs= (default: ='()=) (type: list-of-gexps) :: This is a list of gexps (see [[id:guix--G_002dExpressions][G-Expressions]]), where each gexp corresponds to an mcron job specification (see [[https://www.gnu.org/software/mcron/manual/html_node/Syntax.html#Syntax][mcron job specifications]] in GNU mcron).

  - =log?= (default: =#t=) (type: boolean) :: Log messages to standard output.

  - =log-format= (default: ="~1@*~a ~a: ~a~%"=) (type: string) :: =(ice-9 format)= format string for log messages. The default value produces messages like "‘=pid== ==name==: ==message=="=' (see [[https://www.gnu.org/software/mcron/manual/html_node/Invoking-mcron.html#Invoking-mcron][Invoking]] in GNU mcron). Each message is also prefixed by a timestamp by GNU Shepherd.
