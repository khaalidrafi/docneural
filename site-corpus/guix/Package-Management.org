** 5 Package Management
:PROPERTIES:
:CUSTOM_ID: package-management
:CLASS: chapter
:END:
<<index-packages>>
The purpose of GNU Guix is to allow users to easily install, upgrade, and remove software packages, without having to know about their build procedures or dependencies. Guix also goes beyond this obvious set of features.

This chapter describes the main features of Guix, as well as the package management tools it provides. Along with the command-line interface described below (see [[id:guix--Invoking-guix-package][=guix package=]]), you may also use the Emacs-Guix interface (see [[https://emacs-guix.gitlab.io/website/manual/latest/html_node/index.html#Top][The Emacs-Guix Reference Manual]]), after installing =emacs-guix= package (run M-x guix-help command to start with it):

#+begin_example
guix install emacs-guix
#+end_example
