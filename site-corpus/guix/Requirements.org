*** 22.1 Requirements [[#Requirements-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Requirements-1
:CLASS: section
:END:
You can easily hack on Guix itself using Guix and Git, which we use for version control (see [[id:guix--Building-from-Git][Building from Git]]).

But when packaging Guix for foreign distros or when bootstrapping on systems without Guix, and if you decide to not just trust and install our readily made binary (see [[id:guix--Binary-Installation][Binary Installation]]), you can download a release version of our reproducible source tarball and read on.

This section lists requirements when building Guix from source. The build procedure for Guix is the same as for other GNU software, and is not covered here. Please see the files =README= and =INSTALL= in the Guix source tree for additional details.

GNU Guix is available for download from its website at [[https://guix.gnu.org]].

GNU Guix depends on the following packages:

- [[https://gnu.org/software/guile/][GNU Guile]], version 3.0.x, version 3.0.9 or later;
- [[https://codeberg.org/guile-gcrypt/guile-gcrypt][Guile-Gcrypt]], version 0.1.0 or later;
- [[https://codeberg.org/guile-gnutls/guile-gnutls][Guile-GnuTLS]] (see [[http://gnutls.org/manual/gnutls-guile/Guile-Preparations.html#Guile-Preparations][how to install the GnuTLS bindings for Guile]] in GnuTLS-Guile)[[#FOOT43][^{43}]];
- [[https://codeberg.org/guile-sqlite3/guile-sqlite3][Guile-SQLite3]], version 0.1.0 or later;
- [[https://codeberg.org/guile-compression/guile-zlib][Guile-zlib]], version 0.1.0 or later;
- [[https://codeberg.org/guile-compression/guile-lzlib][Guile-lzlib]];
- [[https://www.nongnu.org/guile-avahi/][Guile-Avahi]];
- [[https://codeberg.org/guile-git/guile-git][Guile-Git]], version 0.10.0 or later;
- [[https://git-scm.com][Git]] (yes, both!);
- [[https://github.com/aconchillo/guile-json][Guile-JSON]] 4.3.0 or later;
- [[https://www.gnu.org/software/make/][GNU Make]].

The following dependencies are optional:

- Support for build offloading (see [[id:guix--Daemon-Offload-Setup][Using the Offload Facility]]) and =guix copy= (see [[id:guix--Invoking-guix-copy][Invoking =guix copy=]]) depends on [[https://github.com/artyom-poptsov/guile-ssh][Guile-SSH]], version 0.13.0 or later.
- [[https://codeberg.org/guile-compression/guile-zstd][Guile-zstd]], for zstd compression and decompression in =guix publish= and for substitutes (see [[id:guix--Invoking-guix-publish][Invoking =guix publish=]]).
- [[https://ngyro.com/software/guile-semver.html][Guile-Semver]] for the =crate= importer (see [[id:guix--Invoking-guix-import][Invoking =guix import=]]).
- [[https://www.nongnu.org/guile-lib/doc/ref/htmlprag/][Guile-Lib]] for the =go= importer (see [[id:guix--Invoking-guix-import][Invoking =guix import=]]) and for some of the “updaters” (see [[id:guix--Invoking-guix-refresh][Invoking =guix refresh=]]).
- When [[http://www.bzip.org][libbz2]] is available, =guix-daemon= can use it to compress build logs.

Unless =--disable-daemon= was passed to =configure=, the following packages are also needed:

- [[https://gnupg.org/][GNU libgcrypt]];
- [[https://sqlite.org][SQLite 3]];
- [[https://gcc.gnu.org][GCC's g++]], with support for the C++11 standard.
