*** 6.1 Specifying Additional Channels
:PROPERTIES:
:CUSTOM_ID: specifying-additional-channels
:CLASS: section
:END:
<<index-extending-the-package-collection-_0028channels_0029>> <<index-variant-packages-_0028channels_0029>>
You can specify /additional channels/ to pull from. To use a channel, write =~/.config/guix/channels.scm= to instruct =guix pull= to pull from it /in addition/ to the default Guix channel(s):

<<index-_0025default_002dchannels>>

#+begin_src lisp
;; Add variant packages to those Guix provides.
(cons (channel
        (name 'variant-packages)
        (url "https://example.org/variant-packages.git"))
      %default-channels)
#+end_src

Note that the snippet above is (as always!) Scheme code; we use =cons= to add a channel the list of channels that the variable =%default-channels= is bound to (see [[https://www.gnu.org/software/guile/manual/html_node/Pairs.html#Pairs][=cons= and lists]] in GNU Guile Reference Manual). With this file in place, =guix pull= builds not only Guix but also the package modules from your own repository. The result in =~/.config/guix/current= is the union of Guix with your own package modules:

#+begin_example
$ guix describe
Generation 19   Aug 27 2018 16:20:48
  guix d894ab8
    repository URL: https://git.guix.gnu.org/guix.git
    branch: master
    commit: d894ab8e9bfabcefa6c49d9ba2e834dd5a73a300
  variant-packages dd3df5e
    repository URL: https://example.org/variant-packages.git
    branch: master
    commit: dd3df5e2c8818760a8fc0bd699e55d3b69fef2bb
#+end_example

The output of =guix describe= above shows that we're now running Generation 19 and that it includes both Guix and packages from the =variant-packages= channel (see [[id:guix--Invoking-guix-describe][Invoking =guix describe=]]).
