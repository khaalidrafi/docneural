*** 15.2 Supported Platforms [[#Supported-Platforms-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Supported-Platforms-1
:CLASS: section
:END:
The =(guix platforms …)= modules export the following variables, each of which is bound to a =platform= record.

- Variable: *armv7-linux* [[#index-armv7_002dlinux][¶]] :: Platform targeting ARM v7 CPU running GNU/Linux.

- Variable: *aarch64-linux* [[#index-aarch64_002dlinux][¶]] :: Platform targeting ARM v8 CPU running GNU/Linux.

- Variable: *loongarch64-linux* [[#index-loongarch64_002dlinux][¶]] :: Platform targeting loongarch 64-bit CPU running GNU/Linux.

- Variable: *mips64-linux* [[#index-mips64_002dlinux][¶]] :: Platform targeting MIPS little-endian 64-bit CPU running GNU/Linux.

- Variable: *powerpc-linux* [[#index-powerpc_002dlinux][¶]] :: Platform targeting PowerPC big-endian 32-bit CPU running GNU/Linux.

- Variable: *powerpc64le-linux* [[#index-powerpc64le_002dlinux][¶]] :: Platform targeting PowerPC little-endian 64-bit CPU running GNU/Linux.

- Variable: *riscv64-linux* [[#index-riscv64_002dlinux][¶]] :: Platform targeting RISC-V 64-bit CPU running GNU/Linux.

- Variable: *i686-linux* [[#index-i686_002dlinux][¶]] :: Platform targeting x86 CPU running GNU/Linux.

- Variable: *x86_64-linux* [[#index-x86_005f64_002dlinux][¶]] :: Platform targeting x86 64-bit CPU running GNU/Linux.

- Variable: *x86_64-linux-x32* [[#index-x86_005f64_002dlinux_002dx32][¶]] :: Platform targeting x86 64-bit CPU running GNU/Linux with the run-time using the X32 ABI.

- Variable: *i686-mingw* [[#index-i686_002dmingw][¶]] :: Platform targeting x86 CPU running Windows, with run-time support from MinGW.

- Variable: *x86_64-mingw* [[#index-x86_005f64_002dmingw][¶]] :: Platform targeting x86 64-bit CPU running Windows, with run-time support from MinGW.

- Variable: *i586-gnu* [[#index-i586_002dgnu][¶]] :: Platform targeting x86 CPU running GNU/Hurd (also referred to as “GNU”).

- Variable: *avr* [[#index-avr][¶]] :: Platform targeting AVR CPUs without an operating system, with run-time support from AVR Libc.

- Variable: *or1k-elf* [[#index-or1k_002delf][¶]] :: Platform targeting OpenRISC 1000 CPU without an operating system and without a C standard library.

- Variable: *xtensa-ath9k-elf* [[#index-xtensa_002dath9k_002delf][¶]] :: Platform targeting Xtensa CPU used in the Qualcomm Atheros AR7010 and AR9271 USB 802.11n NICs (Network Interface Controllers).
