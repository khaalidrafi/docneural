*** 13.3 =home-environment= Reference [[#home_002denvironment-Reference-1][¶]]
:PROPERTIES:
:CUSTOM_ID: home_002denvironment-Reference-1
:CLASS: section
:END:
The =home-environment= record type, provided by =(gnu home)=, lets you declare your home environment---see [[id:guix--Declaring-the-Home-Environment][Declaring the Home Environment]], for an example. This section documents all the fields of =home-environment=.

- Data Type: *home-environment* [[#index-home_002denvironment-1][¶]] :: This is the data type representing the configuration of a “home environment”---packages and services installed for your user account. It has the following fields.

  - =packages= (default: ='()=) :: The list of packages to be installed in your environment. These packages are then visible under =~/.guix-home/profile=.

  - =services= (default: =%base-home-services=) :: The list of services available in your home environment. See [[id:guix--Home-Services][Home Services]], for a list of available services.

  - =essential-services= (default: ...) :: The list of /essential services/---services without which Guix Home may not work properly. See [[id:guix--Essential-Home-Services][Essential Home Services]].

    The default value should almost always be kept unchanged.

  - =transformation= (default: =identity=) :: A one-argument procedure that, when passed a file-like object, returns another file-like object (see [[id:guix--G_002dExpressions][G-Expressions]], for more on file-like objects).

    This procedure is called for every file-like object---including but not limited to packages---that appears while lowering the home environment to a derivation, and is thus in a key position to customize what goes in your home environment.

    For example, here is how you would tune every package in your home environment for the =x86-64-v4= micro-architecture group:

    #+begin_src lisp
    (use-modules (guix transformations))

    (home-environment
      ;; ...
      (transformation
        (options->transformation '((tune . "x86-64-v4"))
                                 ;; Don't warn about non-tunable
                                 ;; packages.
                                 #:warn? #f)))
    #+end_src

    See [[id:guix--Package-Transformation-Options][Package Transformation Options]], for info on =options->transformation= and related procedures.

    Note that when your home is created as part of an operating system /via/ =guix-home-service-type= (see [[id:guix--Guix-Services::#guix_002dhome_002dservice_002dtype][=guix-home-service-type=]]), it does /not/ inherit the value of the =transformation= field of the operating system.

- Variable: *%base-home-services* [[#index-_0025base_002dhome_002dservices-1][¶]] :: This is the default list of Home services. It contains recommended services, such as =home-log-rotation-service-type= (see [[id:guix--Shepherd-Home-Service][Managing User Daemons]]).
