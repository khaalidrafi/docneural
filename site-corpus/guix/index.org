* GNU Guix
:PROPERTIES:
:CUSTOM_ID: gnu-guix
:CLASS: top
:END:
This document describes GNU Guix version 1.5.0, a functional package management tool written for the GNU system.

This manual is also available in Simplified Chinese (see [[https://guix.gnu.org/manual/1.5.0/zh-cn/html_node/index.html#Top][GNU Guix参考手册]]), French (see [[https://guix.gnu.org/manual/1.5.0/fr/html_node/index.html#Top][Manuel de référence de GNU Guix]]), German (see [[https://guix.gnu.org/manual/1.5.0/de/html_node/index.html#Top][Referenzhandbuch zu GNU Guix]]), Spanish (see [[https://guix.gnu.org/manual/1.5.0/es/html_node/index.html#Top][Manual de referencia de GNU Guix]]), Italian (see [[https://guix.gnu.org/manual/1.5.0/it/html_node/index.html#Top][Manuale di riferimento di GNU Guix]]), Brazilian Portuguese (see [[https://guix.gnu.org/manual/1.5.0/pt-br/html_node/index.html#Top][Manual de referência do GNU Guix]]), and Russian (see [[https://guix.gnu.org/manual/1.5.0/ru/html_node/index.html#Top][Руководство GNU Guix]]).
