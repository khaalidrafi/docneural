*** A.2 Add-on Packages [[#Add_002don-Packages-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Add_002don-Packages-1
:CLASS: appendixsec
:END:
Various authors wrote many add-on packages for Org. Some of these packages used to be part of the ‘=org-mode=' repository but are now hosted in a separate ‘=org-contrib=' repository [[https://git.sr.ht/~bzg/org-contrib][here]]. A Worg page with more information is at: [[https://orgmode.org/worg/org-contrib/]].
