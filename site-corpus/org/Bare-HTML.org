**** 13.9.5 Exporting to minimal HTML [[#Exporting-to-minimal-HTML][¶]]
:PROPERTIES:
:CUSTOM_ID: Exporting-to-minimal-HTML
:CLASS: subsection
:END:
If you want to output a minimal HTML file, with no CSS, no JavaScript, no preamble or postamble, here are the variable you would need to set:

#+begin_src lisp-preformatted
(setq org-html-head ""
      org-html-head-extra ""
      org-html-head-include-default-style nil
      org-html-head-include-scripts nil
      org-html-preamble nil
      org-html-postamble nil
      org-html-use-infojs nil)
#+end_src
