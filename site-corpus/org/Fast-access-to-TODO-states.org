**** 5.2.4 Fast access to TODO states [[#Fast-access-to-TODO-states-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Fast-access-to-TODO-states-1
:CLASS: subsection
:END:
If you would like to quickly change an entry to an arbitrary TODO state instead of cycling through the states, you can set up keys for single-letter access to the states. This is done by adding the selection character after each keyword, in parentheses[[#FOOT40][^{40}]]. For example:

#+begin_src lisp-preformatted
(setq org-todo-keywords
      '((sequence "TODO(t)" "|" "DONE(d)")
        (sequence "REPORT(r)" "BUG(b)" "KNOWNCAUSE(k)" "|" "FIXED(f)")
        (sequence "|" "CANCELED(c)")))
#+end_src

If you then press C-c C-t followed by the selection key, the entry is switched to this state. SPC can be used to remove any TODO keyword from an entry.
