**** 13.10.2 LaTeX specific export settings [[#LaTeX-specific-export-settings-1][¶]]
:PROPERTIES:
:CUSTOM_ID: LaTeX-specific-export-settings-1
:CLASS: subsection
:END:
The LaTeX export backend has several additional keywords for customizing LaTeX output. Setting these keywords works similar to the general options (see [[id:org--Export-Settings][Export Settings]]).

-  <<index-DESCRIPTION_002c-keyword-2>>‘=DESCRIPTION=' [[#index-DESCRIPTION_002c-keyword-2][¶]] :: The document's description. The description along with author name, keywords, and related file metadata are inserted in the output file by the hyperref package. See =org-latex-hyperref-template= for customizing metadata items. See =org-latex-title-command= for typesetting description into the document's front matter. Use multiple ‘=DESCRIPTION=' keywords for long descriptions.

-  <<index-LANGUAGE_002c-keyword-1>>‘=LANGUAGE=' [[#index-LANGUAGE_002c-keyword-1][¶]] :: Language code of the primary document language. When ‘=LANGUAGE=' keyword is not specified use the value of =org-export-default-language= (by default - ‘=en=', American English)

  The list of language codes supported by Org is stored in the variable =org-latex-language-alist=.

  In order to be effective, the ‘=babel=' or ‘=polyglossia=' packages---according to the LaTeX compiler used---must be loaded with the appropriate language as argument. This can be accomplished by modifying the =org-latex-packages-alist= variable, e.g., with the following snippet (note that ‘=polyglossia=' does not work with pdfLaTeX):

  #+begin_src lisp-preformatted
  (add-to-list 'org-latex-packages-alist
               '("AUTO" "babel" t ("pdflatex" "xelatex" "lualatex")))
  (add-to-list 'org-latex-packages-alist
               '("AUTO" "polyglossia" t ("xelatex" "lualatex")))
  #+end_src

-  <<index-LATEX_005fCLASS_002c-keyword>>‘=LATEX_CLASS=' [[#index-LATEX_005fCLASS_002c-keyword][¶]] :: This is LaTeX document class, such as /article/, /report/, /book/, and so on, which contain predefined preamble and headline level mapping that the LaTeX export backend needs. The backend reads the default class name from the =org-latex-default-class= variable. Org has /article/ as the default class. A valid default class must be an element of =org-latex-classes=.

- <<index-LATEX_005fCLASS_005fOPTIONS_002c-keyword>>‘=LATEX_CLASS_OPTIONS=' [[#index-LATEX_005fCLASS_005fOPTIONS_002c-keyword][¶]] :: Options the LaTeX export backend uses when calling the LaTeX document class.

-  <<index-LATEX_005fCOMPILER_002c-keyword-1>>‘=LATEX_COMPILER=' [[#index-LATEX_005fCOMPILER_002c-keyword-1][¶]] :: The compiler, such as ‘=pdflatex=', ‘=xelatex=', ‘=lualatex=', for producing the PDF. See =org-latex-compiler=.

-  <<index-LATEX_005fHEADER_002c-keyword-1>>‘=LATEX_HEADER=', ‘=LATEX_HEADER_EXTRA=' [[#index-LATEX_005fHEADER_002c-keyword-1][¶]] :: Arbitrary lines to add to the document's preamble, before the hyperref settings. See =org-latex-classes= for adjusting the structure and order of the LaTeX headers.

- <<index-LATEX_005fCLASS_005fPRE_002c-keyword>>‘=LATEX_CLASS_PRE=' [[#index-LATEX_005fCLASS_005fPRE_002c-keyword][¶]] :: Arbitrary lines to prepend before the LaTeX preamble.

-  <<index-KEYWORDS_002c-keyword-2>>‘=KEYWORDS=' [[#index-KEYWORDS_002c-keyword-2][¶]] :: The keywords for the document. The description along with author name, keywords, and related file metadata are inserted in the output file by the hyperref package. See =org-latex-hyperref-template= for customizing metadata items. See =org-latex-title-command= for typesetting description into the document's front matter. Use multiple ‘=KEYWORDS=' lines if necessary.

-  <<index-SUBTITLE_002c-keyword-3>>‘=SUBTITLE=' [[#index-SUBTITLE_002c-keyword-3][¶]] :: The document's subtitle. It is typeset as per =org-latex-subtitle-format=. If =org-latex-subtitle-separate= is non-=nil=, it is typed outside the =\title= macro. See =org-latex-hyperref-template= for customizing metadata items. See =org-latex-title-command= for typesetting description into the document's front matter.
