*** 12.3 Subscripts and Superscripts [[#Subscripts-and-Superscripts-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Subscripts-and-Superscripts-1
:CLASS: section
:END:
‘=^=' and ‘=_=' are used to indicate super- and subscripts. To increase the readability of ASCII text, it is not necessary, but OK, to surround multi-character sub- and superscripts with curly braces. For example

#+begin_example
The radius of the sun is R_sun = 6.96 x 10^8 m.  On the other hand,
the radius of Alpha Centauri is R_{Alpha Centauri} = 1.28 x R_{sun}.
#+end_example

If you write a text where the underscore is often used in a different context, Org's convention to always interpret these as subscripts can get in your way. Configure the variable =org-use-sub-superscripts= and/or =org-export-with-sub-superscripts= to change this convention. For example, when setting these variables to ={}=, ‘=a_b=' is not displayed/exported[[#FOOT110][^{110}]] as a subscript, but ‘=a_{b}=' is.

You can set both =org-use-sub-superscripts= =org-export-with-sub-superscripts= in a file using the export option ‘=^:=' (see [[id:org--Export-Settings][Export Settings]]). For example, ‘=#+OPTIONS: ^:{}=' sets the two options to ={}= and limits super- and subscripts to the curly bracket notation.

You can also toggle the visual display of super- and subscripts:

-  <<index-C_002dc-C_002dx-_005c>>C-c C-x \ (=org-toggle-pretty-entities=) [[#index-C_002dc-C_002dx-_005c][¶]] :: This command formats sub- and superscripts in a WYSIWYM way.

Set both =org-pretty-entities= and =org-pretty-entities-include-sub-superscripts= to =t= to start with super- and subscripts /visually/ interpreted as specified by the option =org-use-sub-superscripts=.
