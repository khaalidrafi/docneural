*** 4.6 Using Links Outside Org [[#Using-Links-Outside-Org-1][¶]]
:PROPERTIES:
:CUSTOM_ID: Using-Links-Outside-Org-1
:CLASS: section
:END:
You can insert and follow links that have Org syntax not only in Org, but in any Emacs buffer. For this, Org provides two functions: =org-insert-link-global= and =org-open-at-point-global=.

You might want to bind them to globally available keys. See [[id:org--Activation][Activation]] for some advice.
